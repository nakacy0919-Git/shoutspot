# SHOUT SPOT! — VS Code Pack v2

カードの絵を見つけて、英語で叫ぶゲームです。ブラウザーで動く **HTML / CSS / JavaScript** 版です。ビルド・外部ライブラリ・APIキー・Google Apps Script は必要ありません。

## 今回の新しい演出（v2）

1. 起動直後は、カラフルな **SHOUT SPOT! オープニング** が動きます。
2. **PLAY NOW** を押すと、まず **カードAが１枚だけ中央に** 表示されます（約0.55秒）。
3. **カードBが右からスライドイン** して、カードAは左の位置に移動します（約0.8秒）。
4. ２枚がそろったら **SHOUT!** に切り替わり、答えを受け付けます。**PLAY の操作でマイクを先に準備する** 設計です（Safari等ではユーザー操作が必要になる場合があるため）。
5. **最初に認識結果が確定すると、正解でも不正解でもいったん停止します。** 正解なら発言者を選んで得点、不正解なら発言者を確認してお手つきを確定、または認識ミスを取り消します。
6. **次のカード** を押すと同じ登場アニメーションを繰り返します。正解後の得点は自動で加算しません（誰が言ったかの確認が必要）。

音声が始まらない場合は **「マイクを再開」** を押してください。音声認識が使えないブラウザーでも **絵をタップ** すれば回答できます。

## Windows + VS Code で起動

1. ZIPを展開し、VS Codeの「フォルダーを開く」で `shout-spot` フォルダーを開きます。
2. ターミナルで次を実行します。

```powershell
npm start
```

3. PCのChromeなどで **http://localhost:3000** を開き、**PLAY NOW** を押します。
4. 初回のマイクの許可を求められたら許可します。止めるときはターミナルで `Ctrl + C`。

`npm install` は不要です。Node.js 18以上で動作します。`start.bat` での起動、VS Codeの Live Server からの起動も可能です。`index.html` をファイルとしてダブルクリックする起動方法は避けてください。

テスト：

```powershell
npm test
```

## 遊び方と得点

- 「ないもの探し」：左にあって右にない絵を英語で叫びます。
- 「おなじもの探し」：２枚に共通している絵を英語で叫びます。
- １〜８人プレイ、4・6・8個の絵、動物／食べもの／もの／ミックス、全10ラウンド。
- 先に正解を言った人のプレイヤーボタンを押して **＋１点**。次の問題に進めます。
- 不正解が認識された場合は **PAUSED**。誰がお手つきしたか確認してタップすると、その問題のみお休み。**認識ミスなら必ず「取り消して続ける」** を使ってください。
- 音声認識は「話者の区別」をしません。誰が先に言ったか／お手つきしたかは、参加者や先生が判断してください。
- 誤認識を含め、**確定した正解以外の言葉はお手つき候補** になります。周囲の話し声でも停止する可能性があります。
- 聞き取りが無音で終わったときは、画面がプレイ中なら自動再接続を試みます。許可がない、ネットワークが使えない場合は再開ボタンを試してください。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | オープニング画面、ゲーム本体、設定・結果画面 |
| `css/style.css` | オープニング演出、カード移動、デザイン・モバイル対応 |
| `js/app.js` | 画面状態、演出時間、音声受付・停止、得点・お手つき |
| `js/engine.js` | 48個の絵とカード・正解の生成 |
| `js/speech.js` | 英語音声認識、単語の別名・言い換え判定 |
| `server.js` / `start.bat` | ローカル起動 |
| `tests/verify.mjs` | 自動テスト（音声とDOMを模擬） |

## iPad利用時の注意

- iPadは原則 **HTTPSで公開したページ** をSafariなどの対応ブラウザーで開いてください。PC上の `localhost` はiPadからは開けません。
- マイクは **Web Speech API** に依存するため、端末・ブラウザーのバージョン・許可・通信状況によって挙動が異なります。特にSafariでは、音声認識開始にユーザー操作が必要になる場合があります。その場合はマイク再開ボタンを使ってください。
- ブラウザーの音声認識実装によっては、外部の音声認識サービスに音声が送られる場合があります。このゲーム自体は録音データを保存しません。
- 音声認識のテストは模擬音声イベントで行っています。**実機のiPadでのマイク認識は別途確認** してください。

## カスタマイズ

`PREVIEW_MS=550` と `SLIDE_MS=800`（`js/app.js` 冒頭）を変更すると、カードの演出時間を調整できます。スライドの実際の動きは `css/style.css` の `.playfield>.card-wrap` の `transition` と合わせて変更してください。

絵を増やす場合は `js/engine.js` の `items` に `['🦊','fox','キツネ','animals']` の形式で追加します。言い換えは `js/speech.js` の `aliases` に追加します。
