# Shout Spot v3.0 — 英語・日本語 / iPad 対応

円形のカード2枚を見比べ、絵の名前を **英語または日本語** で叫ぶ、音声認識付きの授業用ゲームです。HTML/CSS/Vanilla JavaScriptのみで動き、外部APIキーやデータベースは不要です。

## ローカル起動

VS Codeでこの `shout-spot` フォルダーを開き、PowerShellで：

```powershell
npm test
npm start
```

ブラウザーで `http://localhost:3000` を開きます。音声認識はブラウザーの対応状況とマイク許可に依存します。iPadでの実機認識は端末・OS・ブラウザーの組み合わせごとに確認してください。HTTPSのVercelサイトならマイクを使用しやすくなります。認識が使えなくても絵のタップで参加できます。

## 遊び方

1. オープニングで設定（任意）を変更し、**PLAY NOW** を押します。
2. 最初のカードAが約550ms表示された後、カードBが右から約800msでスライドします。
3. **Bのスライド完了後** に回答受付開始。英語または日本語で絵の名前を叫びます。iPadの音声認識を可能にするため、PLAYのタップ時に先にマイク権限を要求・準備する場合がありますが、アニメーション中に認識した言葉は判定しません。
4. 最終音声認識結果が正解なら音声認識を停止し、正解の絵を表示します。**先に言ったプレイヤー**をタップして＋1点を与えます。声から誰が話したかを自動判定する機能はありません。
5. 誤答ならゲームを一時停止します。「認識ミス？取り消して続ける」で再開、または話したプレイヤーを選択してその問題はお休み（次の問題で復帰）にします。全員がお手つきなら得点なしで次の問題に進めます。
6. 次へを押すと次のカードになり、10問で結果を表示します。

## 音声認識の判定ルール

- 途中経過（interim）は判定せず、**最終結果（final）** だけで判定します。複数の認識候補があるときは正解に一致する候補を優先します。
- 「カードにある絵の名前だけ」（デフォルト）：正解の絵で正解、その他に出ている絵の名前でお手つき確認、関係ない会話は無視します（ノイズによる中断の低減）。
- 「認識した発言はすべて判定」：正解以外の認識結果でいったん停止します（通常の教室では誤停止が増える可能性あり）。
- 無音での認識終了はお手つきではありません。ブラウザーが許可する範囲で認識を自動再接続します。
- マイクの許可拒否、ブラウザー非対応、通信エラーがある場合には、**絵のタップで回答**できます。
- マイク切り替えボタンでいつでも音声認識を停止・再開できます。画面を離れた際は自動停止します。

## 設定

- **言語：** 初回設定で `English (en-US)` / `日本語 (ja-JP)` を選択。プレイ中は右上の `🌐 EN / 🌐 JP` をタップすると即時切り替えます（得点・問題数は維持）。正解発音ボタンも言語に合わせます。
- **絵の数：** 3〜8個。ゲーム画面の `− / ＋` から変更でき、**次の問題から反映**されます（スコアは維持）。設定画面で変更して「この設定ではじめる」を押したときは最初からやり直します。
- **モード：** 「ないもの探し」では左N個・右N−1個、「おなじもの探し」では左右N個、共通する絵は1個だけです。
- **カテゴリー：** 全絵 / 動物 / 食べもの / 身の回り。
- **プレイヤー：** 1〜8人。1台のiPadを囲んでプレイできます。
- **ヒント：** 英語/日本語の単語ラベルを表示・非表示。

## iPad表示

iPad系の縦向き・横向きの両方を想定し、画面の高さに応じてカードと操作パネルのサイズを調整します。ブラウザー画面の高さが足りない場合はSafariの表示を広げるか、ホーム画面に追加して起動してください。実際のSafari/iPadでの検証は別途必要です。

## GitHub → Vercel

GitHubの `main` ブランチがVercelに接続されている場合、次のコマンドで公開ページが更新されます。

```powershell
npm test
git add .
git commit -m "Shout Spot v3 bilingual iPad and voice rules"
git push origin main
```

Vercelのフレームワークは `Other` を選択し、`index.html` があるルートディレクトリーを公開してください。ビルド不要の静的サイトです（`server.js` はローカル起動用）。
